# WESTY Portfolio

Це самодостатній статичний сайт-портфоліо. Усі стилі, ілюстрації та анімації
вбудовані в `index.html`; додаткові залежності або сервер не потрібні.

## Перегляд

Відкрийте `index.html` у браузері.

## Публікація через GitHub Pages

1. Створіть окремий GitHub-репозиторій і завантажте до нього `index.html`.
2. У репозиторії відкрийте **Settings → Pages**.
3. У блоці **Build and deployment** виберіть **Deploy from a branch**.
4. Виберіть гілку `main`, папку `/(root)` і натисніть **Save**.
5. Після публікації відкрийте адресу, показану в налаштуваннях Pages.

Контакти, статистика, послуги та тексти редагуються безпосередньо в `index.html`.
